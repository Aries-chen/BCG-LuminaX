# BCGNet patient-level evaluation feasibility

The Wang 2017 release supports whole-record respiratory event counting. Patient-level AHI3% evaluation additionally requires a matched PSG reference and a sleep-time denominator. The 32-patient pilot provides labeled, scored 120-second windows and a checkpoint for whole-record inference. [Wang 2017 audit](wang2017-bcg-audit.md) · [Pilot results](wang2017-bcg-pilot.md)

## What BCGNet discloses

- The paper uses 30-minute context windows, slides them across the full night at inference, and divides the count of predicted events by total sleep time (TST) in hours. Supplementary Table 9 describes a 6-minute stride in the whole-night latency experiment. AHI3% follows AASM Recommended Rule 1A, with qualifying hypopneas associated with at least 3% oxygen desaturation or an arousal. [Inference methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC13696710/#Sec22) · [Supplementary files](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13696710/supplementaryFiles)
- The repository's event evaluator applies sigmoid, thresholds scores, extracts contiguous one-second segments, merges segments with a configured tolerance of 2 seconds, and uses a 10-second minimum predicted duration in its AP path. It sweeps scores from 0.00 to 0.99 by 0.01, scores interval matches by IoU greater than 0.5, and computes interpolated event AP at 11 recall levels. The test logger accumulates counts by ID and reports event precision, recall, and F1 at the 0.50 threshold. [Event conversion and matching](https://github.com/FiveSeasonsMedical/BCGNet/blob/main/metrics/event_eval.py#L36-L71) · [Event AP](https://github.com/FiveSeasonsMedical/BCGNet/blob/main/metrics/event_eval.py#L277-L310) · [Patient-level event metrics](https://github.com/FiveSeasonsMedical/BCGNet/blob/main/tasks/ahi.py#L148-L198)
- The released test logger documents per-ID event metrics. The published figures additionally require whole-night score fusion and a TST source. The exact Figure 3–5 threshold, overlap-fusion rule, and source of the prediction denominator could not be confirmed from the paper, supplement, and released evaluator. The default branch also has a `stage` argument in `process_cls_for_AP_matrix` while `AHITask` calls it with two arguments. Its segment converter uses zero as a start sentinel and has no flush at the end of the sequence. Boundary behavior needs validation in any reimplementation. [Segment converter](https://github.com/FiveSeasonsMedical/BCGNet/blob/main/metrics/event_eval.py#L197-L212) · [Test caller](https://github.com/FiveSeasonsMedical/BCGNet/blob/main/tasks/ahi.py#L148-L166)

## Applying the method to our checkpoint

Each pilot test patient has 5,760 scored seconds, or 1.6 hours, distributed across the night. That covers 16.3–21.7% of these recordings. In the example window for subject `1064`, the two annotated intervals overlap the window for 44 seconds and the highest model sigmoid score is 0.4533. A cutoff of 0.50 yields zero candidates in this window, which is a concrete reason to select and freeze the operating threshold on validation patients. [Pilot results](wang2017-bcg-pilot.md)

Whole-record inference can reuse the 120-second checkpoint with a proposed 60-second stride. Map scores to absolute time, fuse overlaps into one score per valid second, and decode contiguous half-open intervals on the stitched timeline. Fit the threshold or choose the operating point on validation, then freeze it before test. Check intervals at second zero, the last second, window boundaries, and gaps in valid coverage. The BCGNet values of a two-second gap tolerance and a ten-second minimum duration provide baseline settings for this evaluation.

For the recording-hour endpoint, use the same scored recording coverage as the denominator and the same interval inclusion rule for reference and prediction. Store subject ID, valid coverage, annotated and predicted counts, recording hours, and both rates. Produce Fig. 3- and Fig. 4-style plots after full scoring. For AHI3%, obtain patient-matched PSG AHI3% or sleep epochs and compatible event annotations. Use the recorded TST source explicitly when comparing the event detector alone against a system with a predicted sleep mask.
